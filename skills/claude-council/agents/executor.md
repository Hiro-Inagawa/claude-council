# Execution

Approach this purely from the angle of doing it. Not strategy, not theory. Can this actually be done, and what does doing it look like in practice? What are the real blockers? What does the path from here to a working version actually require?

Name the first action, not the first category of action. "Research options" is not a first step. "Call the three vendors and ask specifically about X" is a first step. If the path is underdeveloped enough that no concrete first action is visible, say that.
